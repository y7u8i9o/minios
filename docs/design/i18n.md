# Translated desktop

The programs of the desktop show their text in the language of the locale.
They use the message catalogues of `gettext.md` and the locales of
`locale.md`. Chinese and Japanese text uses a CJK fallback font.

## Programs and domains

`app_create` calls `setlocale(LC_ALL, "")`. Every libgui program
therefore follows `LANG`, `LC_ALL` and the `LC_*` variables of its
environment. A
program includes `<gui/i18n.h>`, which defines `_(s)` as `gettext(s)` and
`N_(s)` as `s`, and calls `textdomain` with its domain after
`app_create`. A string in a static table is marked with `N_()` and
translated with `_()` where it is shown. A text with a count uses
`ngettext`. The panel does not use `app_create` and calls `setlocale`
itself.

| Domain | Program |
|---|---|
| `libgui` | the context menu of the text widgets and the buttons of `app_prompt`, through `dgettext("libgui", ...)` |
| `launcher` | the titles of the launcher entries |
| `panel` | the panel, the launcher menu and the audio applet |
| `desktop` | the desktop and its context menus |
| `settings` | Settings |
| `files` | Files |
| `term` | the terminal |
| `sysmon`, `logview`, `gedit`, `mandel`, `player` | the programs of the same names |

The sources are `user/po/DOMAIN/LL.po` for the languages `fr`, `es`,
`ru`, `zh_CN` and `ja`, and the template `user/po/DOMAIN/DOMAIN.pot`. The
catalogues of the packaged programs (gedit, mandel, player) are installed
in `/usr/share/locale` of the base image with the others. The launcher
translates the title of each entry of `/etc/launcher` and of the package
table with `dgettext("launcher", title)` when it reads them. The template
of the `launcher` domain lists the titles of the base system and of the
packages in `user/packages`. The title of a package outside the tree stays
untranslated.

The strings that programs print to standard output and standard error stay
in English, because the boot tests read them. Configuration keys and
values, file names, MIME types, icon names, the names of fonts, the
states that the kernel reports and the initial window title "gedit" also
stay unchanged. The screenshot program has no graphical interface and has
no catalogue.

Files shows the modification time with `%x %H:%M` in the list and `%c`
in the properties, and its sizes, the numbers of sysmon and the status
texts of mandel and player use the radix character of the locale.

Numbers in data formats do not follow the locale. The SVG reader of
libgui reads its numbers with `strtod_l` in the C locale, because
`strtof` stops at the full stop in a locale with a decimal comma (French,
Spanish and Russian), which left every icon empty. The calculator sets
`LC_NUMERIC` to C after `app_create`, because its keys and expressions
use the full stop.

## Updating a translation

After a change of the marked strings, the template of a domain is written
again with `tools/xgettext.py`:

    tools/xgettext.py -o user/po/settings/settings.pot user/settings/*.c

The new and changed messages of the template are then copied into each
`LL.po` file and translated. The build compiles the `.po` files with
`msgfmt`. A message without a translation is shown in English. A new
language needs a locale file in `/usr/share/i18n/locales` and one `.po`
file per domain.

The translations were written without a native speaker and require a
review before a release.

## The CJK font

The interface font is DejaVu Sans with DejaVu Sans Mono as its fallback.
A fallback font may have a fallback of its own, and `shape_outline` in
`libgui/src/font.c` walks the chain until a font has the glyph. When no
font of the chain has a glyph for a code point of the CJK ranges (U+2E80
to U+FDFF, U+FF00 to U+FFEF and U+20000 to U+3FFFF), libgui takes it from
Droid Sans Fallback Full, `/etc/fonts/DroidSansFallbackFull.ttf`, which
covers the CJK ideographs, kana and Hangul. `tools/fetch_fonts.sh`
downloads the font of the Android Open Source Project (Apache License
2.0) into `third_party/droidfallback`.

The file has 4 MB, and libfont reads a font file into memory. libgui
therefore opens it on first use (`gfx_font_cjk`), and a program that
shows no CJK text does not read it. The fonts of every size use one
loaded copy. The terminal draws wide characters with the same font through the
same function.

## Tests

The boot test `gui_locale` starts the panel with `LANG=ja_JP.UTF-8` and
sysmon with `LANG=fr_FR.UTF-8` and with `LANG=ja_JP.UTF-8`. The compositor
log must name the window titles "Moniteur système" and "システムモニター",
and the launcher menu opens. Screenshots of the Japanese sysmon window and
launcher menu were checked during the development of the test.
